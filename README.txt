ROBLOX GIF PICKER — STARTER EXTENSION

WHAT IT DOES
- Search GIPHY for GIFs with a general-audience ("g") rating.
- Preview results in a Chrome popup.
- Copy the GIF's GIPHY page link.

IMPORTANT
- Roblox chat may reject links and generally does not embed arbitrary GIFs as animated chat images.
- This extension does not send messages automatically or bypass Roblox chat restrictions.
- GIPHY API access requires an API key. Add it inside the extension under “GIF search setup”.
- Keep this as a local/private test extension. Do not publish an API key in public source code.
- The API provider's terms, rate limits, and attribution requirements apply.

INSTALL ON DESKTOP CHROME
1. Extract this ZIP into a folder.
2. Open chrome://extensions in Google Chrome.
3. Turn on Developer mode.
4. Click “Load unpacked”.
5. Select the extracted folder containing manifest.json.
6. Click the extension icon, open “GIF search setup”, and add your GIPHY API key.
7. Search for a reaction and click “Copy GIF link”.

FILES
- manifest.json: extension configuration
- popup.html: popup structure
- popup.css: styles
- popup.js: search and copy behavior
